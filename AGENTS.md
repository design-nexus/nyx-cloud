# Cloud
Rust rclone backend and public client library. Never log secrets or put them in D-Bus metadata. Keep external configurations untouched without explicit user confirmation. Test using isolated temporary remotes and a private bus. Build with cargo build --release --locked; install with ./install.sh. Do not launch/restart apps after installation; restarting background services (such as `systemctl --user restart nyx-cloud.service`) so the new build takes effect is allowed.
